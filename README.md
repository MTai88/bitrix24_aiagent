# bitrix24_aiagent — AI-агент для Битрикс24 (открытые линии, чаты, бизнес-процессы)

Модуль `mtai.aiagent` встраивает AI-агента на базе LLM в три контура портала:

- **Открытые линии** — автономные ответы клиентам по базе знаний (RAG):
  документы (PDF/DOCX/TXT/MD/CSV/HTML) → чанки → эмбеддинги → косинусный
  поиск → ответ LLM. Нет ответа, клиент просит человека или модель
  «выдумывает» (self-check) — диалог передаётся оператору
  (`imopenlines.bot.session.operator/.transfer`), при этом создаётся лид
  (`imopenlines.crm.lead.create`). Агент «видит» привязанные к сессии
  CRM-сущности, уважает рабочие часы.
- **Личные чаты** — управление CRM, задачами и календарём естественным языком:
  «создай сделку для Иванова на 100 000», «мои задачи», «что у меня
  завтра в календаре», «запланируй встречу с Ивановым на 15:00»,
  «запиши в сделку, что клиент обещал оплату». Function calling
  (OpenAI-совместимые) или JSON-протокол (YandexGPT, GigaChat). Действия
  выполняются **с учётом прав сотрудника** (нативные роли CRM: свои/отдел/все;
  календарь — только собственный).
- **Бизнес-процессы** — активность дизайнера «AI-агент» (в духе n8n AI
  Agent): три режима — RAG-ответ, выполнение задачи инструментами CRM,
  прямой запрос к модели; память между узлами, запись ответа в поле
  документа. События — `imbot.v2` в режиме `eventMode=fetch`
  (`imbot.v2.Event.get`), без публичного вебхука.

## Ключевые возможности

| Область | Что умеет |
|---------|-----------|
| LLM | OpenAI-совместимые API (OpenAI, OpenRouter, vLLM, Ollama), YandexGPT, GigaChat (authorization key — access-токен получается автоматически), мок без внешних вызовов |
| База знаний | Две области: публичная (клиентам в линиях) и внутренняя (только сотрудникам); загрузка из админки и командой `/ai-add` с файлом в чате; тест-поиск со скорами |
| Инструменты CRM | поиск/создание/изменение сущностей, задачи с привязкой к CRM, комментарии в таймлайн — с проверкой прав пользователя |
| Календарь | «мой календарь»: события за период, создание событий и встреч с участниками, удаление собственных событий |
| Команды бота | `/ai-help`, `/ai-add`, `/ai-reset`, `/ai-status` |
| Надёжность | асинхронная очередь (агенты Битрикса), ретраи, уведомления админу о сбоях, журнал всех запросов к LLM и REST, шифрование ключей (`Security\Cipher`), Markdown→BBCode |
| Администрирование | настройки (LLM/приложение/линии/чаты/RAG), база знаний, журнал со сводкой |

## Установка

1. Скопируйте `mtai.aiagent/` в `<портал>/local/modules/`.
2. Админка → «Настройки → Настройки продукта → Модули» → установить.
3. Настройте связь с порталом (локальное OAuth-приложение или входящий
   вебхук + botToken), зарегистрируйте бота кнопкой на странице настроек.
4. Подключите LLM-провайдера (ключ), загрузите документы в базу знаний,
   добавьте бота в очередь открытой линии.

Полная документация: [mtai.aiagent/README.md](mtai.aiagent/README.md).

```

├── install/           установщик, админ-страницы, активность бизнес-процесса
├── lib/               ядро: REST-клиент, очередь, LLM-провайдеры, RAG, права
```

## Требования

- Битрикс24 (box) с модулями im, imbot, imopenlines, bizproc, crm, tasks, calendar, rest
- PHP 8.1+ (расширения: curl/openssl, zip, zlib, dom, mbstring)
- Ключ одного из LLM-провайдеров (для проверки конвейера хватит и «Мока»)
